# 魔兽争霸3鼠标操作模拟器

这个项目模拟了魔兽争霸3游戏中的常见鼠标操作，包括：

1. 左键选择单位
2. 右键移动/攻击/使用物品
3. 右键框选单位
4. 鼠标放置屏幕边缘自动移动视角

## 安装依赖

在运行程序之前，请先安装所需的依赖包：

```bash
pip install -r requirements.txt
```

## 运行程序

```bash
python war3helper/mouse.py
```

## 功能说明

- **左键点击**：模拟选择单位的操作
- **右键点击**：模拟移动、攻击或使用物品的操作
- **右键拖拽**：模拟框选多个单位的操作
- **鼠标边缘**：将鼠标移动到屏幕边缘会模拟视角移动
- **退出程序**：按 Esc 键退出模拟器

## 注意事项

1. 本程序仅用于学习和演示目的
2. 实际游戏中的视角移动需要通过游戏API或键盘命令实现，当前版本仅记录日志
3. 运行前请确保已安装所有依赖包

## 配置选项

在 `mouse.py` 文件中，你可以调整以下配置：

- `EDGE_THRESHOLD`：屏幕边缘检测的灵敏度（像素）
- `EDGE_MOVE_SPEED`：边缘移动的速度

## 开发说明

项目结构：
- `war3helper/mouse.py`：鼠标操作模拟的主要代码
- `requirements.txt`：所需的 Python 依赖包
